# KiCad compatibility notice

CirZuit's KiCad Symbol Environment is an independent implementation of the KiCad symbol-library data model and renderer boundary.

This project does **not** copy KiCad's C++ source code into CirZuit. The implementation is based on the publicly documented KiCad symbol-library file format and on observed behavior described by KiCad's developer documentation and source-code interfaces.

KiCad itself is GPL-licensed. KiCad's official symbol libraries are distributed under their own library license terms. When CirZuit fetches official libraries at runtime, users should retain the applicable KiCad library attribution/license information and comply with the terms of the library version they use.
