# KiCad environment notice

CirZuit's KiCad support is implemented as an independent TypeScript object model, file reader boundary, coordinate system, and renderer inspired by the public KiCad symbol file format and official KiCad documentation.

This project does not bundle KiCad's C++ application code.

When distributing KiCad library data, preserve the applicable KiCad library licensing and attribution requirements. Verify the license of each library/data source before redistribution.
