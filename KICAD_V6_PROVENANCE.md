# KiCad V6 Footprint Environment — Provenance

Behavioral references used for the V6 architecture:

- KiCad source: https://gitlab.com/kicad/code/kicad
- `pcbnew/footprint.h`
- `pcbnew/pad.h`
- KiCad Footprint File Format: https://dev-docs.kicad.org/en/file-formats/sexpr-footprint/
- Official Footprint Library: https://gitlab.com/kicad/libraries/kicad-footprints

The V6 TypeScript runtime is an independent implementation of the object and
transform concepts. No KiCad C++ source is copied into this project.
